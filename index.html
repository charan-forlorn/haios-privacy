HAIOS

A governed AI execution system designed to make agent-driven work scoped, reviewable, recoverable, and supported by evidence.

Dropbox integration

The HAIOS R1 Dropbox connector is a local Windows/Python command-line component that retrieves only basic Dropbox account information and storage usage.

  • OAuth permission: account_info.read only.
  • API operations: users/get_current_account and users/get_space_usage.
  • No Dropbox file/folder listing, file content access, upload, download, sharing, or modification.
  • Token and API processing take place in the local connector process; the connector does not maintain a cloud data store.

Availability: R1 is implemented as a local connector. Production activation in the HAIOS Hermes/MCP runtime is not currently enabled.
